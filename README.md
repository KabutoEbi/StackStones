# 「StackStones」という題名にしておけば宗教的にグレーな作品だとバレないはず

## ダウンロード方法
1. 「<> Code▼」>「Download Zip」
2. ダウンロードしたファイルを展開
3. 展開したフォルダ内にある「StackStones.exe」を起動
4. ゲーム終了時は、Alt+F4(Windows)、Command+Q(Mac)でウィンドウを閉じる

## 操作方法
W：右に移動

S：左に移動

スペース：石を壊す

## ルール
30秒間でできるだけ多くの石を壊す。

## スコア
1-3個：1点

4-6個：3点

7-8個：5点

9個：10点

10個：0.5点(5回連打で破壊)
